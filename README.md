# BWA

Telegram-бот для общения с LLM через OpenAI-совместимый API Chat Completions.

Принимает текстовые сообщения и отправляет ответы модели в чат. Поддерживает
отдельные прокси для Telegram и LLM-провайдера. Построен на aiogram и OpenAI SDK.

## Требования

- Python 3.13.
- Git для клонирования репозитория.
- Токен Telegram-бота.
- Доступ к OpenAI-совместимому API и идентификатор модели.

## Установка

Команды для Windows PowerShell:

```powershell
git clone https://github.com/breduv/BWA.git
cd BWA
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка

Создайте `.env` из [шаблона](.env.example):

Замените значения-заглушки своими настройками:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота. |
| `API_BASE` | Базовый URL API провайдера, без `/chat/completions`. |
| `API_KEY` | Ключ API провайдера, если требуется авторизация. |
| `MODEL` | Идентификатор модели у провайдера. |
| `PROXY` | Прокси для запросов к LLM. Необязательно. |
| `TG_PROXY` | Прокси для подключения к Telegram. Необязательно. |

Некоторые провайдеры и локальные LLM-серверы не требуют API-ключа. Текущий SDK ожидает непустое значение: для сервера, который игнорирует заголовок авторизации, укажите `API_KEY=unused`.

Прокси настраиваются независимо. При необходимости раскомментируйте нужную строку в `.env` и укажите URL, например `http://127.0.0.1:8080`. Если прокси не нужен, оставьте строку закомментированной или удалите её; не задавайте пустое значение.

Файл `.env` исключён из Git. Реальные токены и ключи храните в нём, а не в `.env.example`.

## Использование

Запустите бота из корня проекта:

```powershell
.\.venv\Scripts\python.exe main.py
```

Отправьте боту текстовое сообщение в Telegram — он вернёт ответ модели.
История диалога не сохраняется: каждый запрос содержит только текущее сообщение.
Обновления Telegram поступают через long polling.

Для остановки нажмите `Ctrl+C`.
